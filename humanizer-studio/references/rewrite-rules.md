# 人化 7 原则（改写时逐条执行）

1. **开场直接**：删掉"在当今/随着…/值得注意的是"等铺垫，第一句就给信息或画面。
2. **句式多变**：每 3–4 句换一种结构（长句↔短句、陈述↔设问），别全用并列"首先/其次"。
3. **虚词做减法**："可以说/事实上/实际上/某种程度上"能删就删，信息密度拉满。
4. **破模板感**：少用三段整齐排比、少用项目符号堆砌；关键处改成分段口语。
5. **加一个具体细节**：一句真实例子、一个数字、一个个人视角，比十个形容词更"人"。
6. **语气落地**：结尾别喊口号，给一句实在的下一步或一句人话总结。
7. **保留原意**：人化是改"表达"不是改"事实"——术语、数据、结论不动，只动措辞与节奏。

## 轻 / 中 / 重 三档
- **轻**：只删套路词、修语病、合并重复。几乎零偏离，安全。
- **中**：在轻的基础上重组节奏、长短交错、换过渡词。推荐默认档。
- **重**：重写语气、加入口语/个人视角，可能显著改措辞——需用户确认后再给。
