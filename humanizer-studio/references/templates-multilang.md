# 语种替换表（AI 腔 → 人话）

改写时按目标语言把左侧套路替换为右侧自然表达。仅作起点，最终靠语感微调。

## 简体中文（zh-CN）
| AI 腔 | 人话 |
|---|---|
| 值得注意的是 | （直接说，或"有个细节"） |
| 综上所述 / 总而言之 | （删掉，用一句总结人话） |
| 可以说 / 事实上 / 实际上 | （删） |
| 随着…的发展 | （直接说变化） |
| 首先…其次…最后 | （按重要性排，或自然过渡） |
| 赋能 / 闭环 / 抓手 | （换成具体动作：帮…做…） |
| 在快节奏的当下 | （删或"现在"） |

## 繁體中文（zh-TW）
| AI 腔 | 人話 |
|---|---|
| 值得注意的是 | （直接說） |
| 綜上所述 / 總而言之 | （刪，用一句總結） |
| 可以說 / 事實上 | （刪） |
| 隨著…的發展 | （直接說變化） |
| 首先…其次…最後 | （按重要度排） |
| 賦能 / 閉環 / 抓手 | （換成具體動作） |

## 英文（en）
| AI tell | Human |
|---|---|
| It is worth noting that | (drop, or "One thing:") |
| In today's world | (drop, or "Now") |
| Moreover / Furthermore | Also / Plus |
| Delve | Look closely / Dig into |
| Leverage / Utilize | Use |
| In order to | To |
| Game-changer / Robust / Seamless | (specific, concrete word) |

## 日本語（ja）
| AI 腔 | 人話 |
|---|---|
| 言うまでもなく | （削除） |
| 総じて言えば | （削除、一文でまとめ） |
| 〜において | （「で」「に」等に置換） |
| まず…次に…最後に | （重要度順か自然な接続に） |
| 〜である（重複） | （文体を整える） |
