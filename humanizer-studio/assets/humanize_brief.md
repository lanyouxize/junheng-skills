# 人化简报（Intake 清单）

把原文拿来之前，先确认这 6 项。信息不全就追问，不凭空编内容。

1. **待改原文**：直接贴文本，或给文件路径。
2. **目标语言**：zh-CN（简中）/ zh-TW（繁中）/ en（英文）/ ja（日文）。
3. **读者与场景**：朋友圈 / 公众号 / 论文 / 工作报告 / 跨境电商帖 / 其他？
4. **人化强度**：
   - 轻：只润色、删套路词
   - 中：重组句式节奏（推荐）
   - 重：重写语气、加口语/视角
5. **约束**：是否保留专业术语？是否限定字数？是否要保留某些原句？
6. **用途声明**：自用润色 / 公开发布（需披露 AI 辅助）/ 学术（请确认非代写用途）。

> 收到简报后，先跑 `scripts/humanize.py` 做 AI 腔诊断，再按 `references/rewrite-rules.md` 出稿。
