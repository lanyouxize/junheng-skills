> 安装即用的 Token 用量统计面板。扫描本机会话转录，聚合出累计消耗、缓存命中率、每日趋势、模型占比与当前会话拆分，每 30 秒自动刷新。纯 Python 标准库实现，零依赖、零网络上传，离线可用。

## 详细描述（市场页正文）

### 你的 Token 花在哪了？

WorkBuddy / CodeBuddy 的每一轮对话都在消耗 Token，但消耗了多少、什么时候花的、被哪个模型吃掉——软件里很难看全。**Token Usage** 读取本机会话转录，把这些数据变成一面"仪表盘"：

- 📊 **5 张核心指标卡**：累计消耗、当前会话消耗、缓存命中率、峰值（单日）、最长会话时长
- 🔥 **52 周 Token 活动热力图**：GitHub 风格，悬浮显示"当日 tokens · 轮次"
- 📈 **每日趋势图**：近 7 / 30 日切换，按日补零不漏天
- 🍩 **模型用量环形图**：各模型占比，与时间范围联动
- 🎯 **当前会话精准拆分**：自动识别正在使用的会话，单独统计

### 三种输出形态

| 形态 | 场景 |
|---|---|
| 实时面板 | 对话预览区直接看，30 秒自刷新，可收藏为快捷入口 |
| 静态快照 | 自包含 HTML 单文件，可转发、可离线打开 |
| JSON 明细 | 按天 / 按模型 / 按会话全量字段，交给脚本进一步分析 |

### 为什么放心用

- 🔒 **100% 本地处理**：只读本机转录文件，无任何网络上传
- 📴 **离线可用**：图表库已内置插件包内
- 🪶 **零依赖**：纯 Python 标准库（3.8+），不需要 pip 安装任何东西
- 🧹 **干净卸载**：删目录即走，无残留、无后台常驻服务（面板服务随用随开随关）

### 隐私与安全

插件代码不包含任何遥测、上报或外部请求逻辑。唯一涉及网络的场景是首次生成面板时若本地缺少图表库会尝试从 CDN 下载（**市场包已内置，正常情况下不会发生**）。面板服务仅监听 `127.0.0.1`，局域网内其他设备不可访问。

## 版本历史

### v1.0.0（首发）

- 核心：扫描 `~/.codebuddy/projects/**/*.jsonl`，聚合 token 用量
- 四种输出：终端摘要 / 实时面板服务（30s 自刷新）/ 静态 HTML / JSON
- 当前会话自动识别（心跳匹配）；缓存命中率；连续使用天数
- 对话内入口卡片（30s 动态数据 + 点击兜底提示）
- 首次使用对话选择框引导
- 兼容 camelCase / snake_case 两种转录用量格式；时区可配置（`--tz`）

### Roadmap（下版本候选）

- 成本估算（可配置模型单价表）
- 按子代理/项目维度拆分
- 周报自动生成
