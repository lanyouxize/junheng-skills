⚠️ **如果你调用时出现 401**：Key 一栏必须写 `anonymous`（`public`、`none`、`kilo` 都会被拒），或干脆留空——这两种我们都实测通过。

## 路线 C · 要更多模型 / 更快速度（3 分钟，推荐）

**注册 Groq：30 秒，不绑卡，永久免费额度。**

第1 步 · 拿 Key

1. 浏览器打开 `https://console.groq.com/keys`
2. 登录（Google 账号最快）
3. 点「Create API Key」→ 复制那串 `gsk_...`
4. **这串Key 只能你自己保管**，别发给任何人（包括我）

第 2 步 · 填配置（这步只能你操作，Key 我不能代管）

1. 在 WorkBuddy 对话框旁点**模型选择器**
2. 点最下方**「配置自定义模型」**
3. 按下面填（字段名以你界面实际显示为准）：

| 字段 | 填什么 |
|---|---|
| 名称 | 随意，如 `Groq gpt-oss-120b` |
| API 地址 / Base URL | `https://api.groq.com/openai/v1` |
| API Key | 你的 `gsk_...` |
| 模型名 / Model | `gpt-oss-120b` |
| 协议类型 | **OpenAI兼容** |

4. 保存。模型列表里出现它，选中就能直接对话，之后零额外操作。

**Groq 能有什么**（核实 2026-10-07，来源 console.groq.com/docs/rate-limits）：

## 路线 D · 多渠道自动路由 + 故障转移

需要「一个端点接多家免费模型、哪家挂了自动切」。装「自由模型市场·网关」Skill，那个负责部署 OmniRoute。

本 Skill 是它的**额度权威源**——路由优先级会跟着货架数据走。

### ⚠️ 自动切换的三个真相（别误以为装了超市就有）

**1. 超市本身不做切换。** 本 Skill 只回答「有哪些免费渠道、额度多少、选哪个」，是纯咨询层，不在请求路径上。额度耗尽时它不会被触发。

**2. 直连条目没有 fallback。** 路线 B（已不可用）曾注入 `space-bunny-free`、路线 C 自己配的 Groq，都属于「一个 url 指向一个模型」——额度用完就是一条报错，WorkBuddy 不会帮你换。

**3. 只有 combo 才有自动切换。** OmniRoute 的 combo（模型链）按 `models[]` 下标顺序尝试，首个失败自动落到下一个。所以：

| 你想要 | 怎么做 |
|---|---|
| 单个模型直连，简单省事 | 路线 B 或 C。**接受「额度耗尽需手动换」** |
| 一个端点接多家、挂了自动切 | 路线 D。combo 名（如 `free-vision`）要填进 WorkBuddy 模型选择器 |

**关于「额度感知」**：combo 是**按节点失败顺序** fallback 的，不预测「这个模型额度快满了」。额度耗尽通常表现为 429/402，那时它已经在切了——这点符合预期。但它不会提前帮你省额度。

**关于「视觉能力降级」**：只有名字带 vision 的 combo 才保证视觉能力。纯文本 combo 的 fallback 节点可能完全不支持图片。如果你发图后得到的是文字描述，说明已经降级到纯文本模型了——这不是 bug，是链的正常行为。

## 路线 E · 流量省电模式（同样额度跑更多任务）

在 **DeepSeek Harness（DSH）** 里跑任务时，装 `dsh-ops` 能压低每次任务的 token 开销——模型不变，只优化工具清单与加载机制。

- 机制：隐藏/替换部分内置工具减少试探；重工具（PDF/Word、批量改文件）按需加载，系统提示词不常驻膨胀；紧凑返回减少返工轮次。
- 有效场景：token 计量 / 上下文受限 / TPM 受限的额度（Mistral、Inception、Cloudflare、NVIDIA）。
- 效果有限：纯「请求数/日」计量的额度（Groq 1000/日、OpenRouter 50/日）——省 token 不等于少请求。
- 前提：仅 DSH 0.2.0-rc.2–0.2.1-rc.2，Node ^22.19||>=24；以 DSH 进程权限运行，社区维护、非官方，装前自审源码。
- 安装（在 DSH 终端）：`npx --yes dsh-ops@latest install --profile desktop`（web/tui 同理）。

**别把它当「额度翻倍」**：它压缩的是 token 消耗，请求次数未必下降。
