# 视频输入采样最佳实践与 API 踩坑

来源：deepseek-v4-flash-vision-exp-video-input-best-practice 项目实测（2026-08-21）
+ 本 skill 开发过程中的实测。改采样/调用逻辑前必读。

## 核心事实：模型怎么"看"视频

| 方式 | 模型实际看到 | 结论 |
|---|---|---|
| GIF 整段 | **只有第 1 帧**（黑帧探针证实，服务端只解码首帧） | 永远不要用 |
| 按时间顺序的多张 JPEG | 全部帧，时序完整 | **唯一正确方式** |

配套要求：prompt 里必须写明**图片数量、采样率、时间窗口/起始时刻**，
否则模型建立不了时间轴。本 skill 用 `[t=Xs]` 文本标签 + 帧图交错排列实现。

## 两级采样

- **宏观层**（剧情/事件/场景）：全图 JPEG `-q:v 3`，密度按时长自适应
  （1fps → 0.1fps）。720p 全图 ≈384 token/图，640×360 ≈175 token/图
- **微观层**（快速动作，150-250ms 级）：事件窗口内 12fps，中心 40% 区域裁切
  2× lanczos 放大（≈250 token/图）。**裁切必须配 1 张全图锚点**，否则丢上下文
  （实测教训：把队友的 AWP 枪管误判成玩家武器）
- 微观窗口选择：优先运动强度最高的引用时刻（帧卡片的 motion=高），
  本地场景切换检测（scene>0.3）可作章节参考

## API 限制与成本

| 项 | 值 |
|---|---|
| 单请求图片数 | 600 张 |
| 15+ 图/请求 | 单边最长 4096px（本 skill 渲染钳制 3600px） |
| 单图 token | 封顶 384（自动缩放 ~800×800），分辨率不影响费用 |
| 请求体 | base64 ≤48MiB；file_id 方式总量 ≤200MiB |
| Prompt 缓存 | 同批帧二次发送 71s→4.8s（实测有效），迭代便宜 |

## 踩坑清单（全部实测复现过）

1. **thinking 吃 completion 预算**：开推理时 `max_tokens=8192` 会被 reasoning 占满
   → **空 content 且不报错**。深读/微观必须 `max_tokens=32768` 并检查
   `finish_reason`。关推理（`extra_body={"thinking":{"type":"disabled"}}`）不受影响，
   批量索引用关推理 + 8192 即可
2. **`detail=low` 会毁掉小字**（缩到 512×512，HUD/字幕全毁），永远不要用；
   也不要预先降分辨率——API 内部缩放，多传像素不扣 token
3. **时间戳引用是区间**：模型倾向输出 `[00:00-00:07]` 区间而非单时刻，
   解析要两者都支持（`ask.py` 的 `parse_ts`）
4. **1fps 时间轴误差 ±2s**：击杀等事件时刻是估计值；精确时机靠微观层（12fps）
   或片段回放，不要信宏观时间轴
5. **killfeed 类小字只当事件触发器**，不当事实源（武器图标会误判）；
   HUD 大数字可靠（实测 $5850/100HP 全对）
6. **模型无音频模态**：音轨用于定位（ffmpeg 能量峰值）可以，"听到什么"不行

## 能力边界（诚实清单）

- 可靠：剧情/事件时间线、场景切换、OCR 大字、动作有无、宏观统计
- 勉强：快速动作细节（12fps 微观）、非中文小字、killfeed 类图标文字
- 做不到：音频内容、亚像素级时机测量、超过采样密度的瞬时事件（1fps 漏 150ms 级动作）

## ffmpeg 命令速查

```bash
# 宏观抽帧（自适应密度）
ffmpeg -i in.mp4 -vf "fps=1" -q:v 3 macro/f_%05d.jpg
# 微观：中心 40% 裁切 2x 放大 @12fps
ffmpeg -ss {t0} -t 3 -i in.mp4 -vf "fps=12,crop=iw*0.4:ih*0.4,scale=iw*2:ih*2:flags=lanczos" -q:v 2 micro/m_%05d.jpg
# 场景切换检测（本地零成本）
ffmpeg -i in.mp4 -vf "select='gt(scene,0.3)',showinfo" -f null - 2>&1 | grep pts_time
# 切可播放片段（无损，关键帧对不齐自动重编码）
ffmpeg -ss {a} -i in.mp4 -t {b-a} -c copy clip.mp4
```
