# 宠物营养需要知识库（Pet Nutrition Needs）

## 概述（Purpose）

为宠物食品配方研发、营养宣称循证、日粮营养浓度核算提供**可直接查表与换算的犬猫核心营养需要量基准**，并具备**主动联网完善**能力——在本地蒸馏知识库基础上，从 NRC/AAFCO/FEDIAF 官方标准、学术文献、GitHub 开源项目与宠物营养专业社群检索，对知识体系做补全、交叉验证与更新。

知识底座为 NRC《犬猫营养需要》（2006 中文版）蒸馏稿，所有数值带来源、不臆造。

## 何时使用（When to Use）

- 用户询问犬/猫某营养素「需要多少」「安全上限」「缺乏后果」「第一限制性氨基酸」，或索要**必需氨基酸需要量表（维持/生长）**、**维生素 D 过量中毒阈值与案例**。
- 配方核算：给定目标动物体重/阶段/活动量，反推每 kg 日粮营养浓度。
- 跨标准对比：NRC vs AAFCO vs FEDIAF；法规更新；现代议题（无谷 DCM、生骨肉、D3 过量）。
- 饲喂禁忌 / 有毒食物：巧克力、木糖醇、葱属、葡萄、澳洲坚果等对犬猫的毒性与处理（§10.5）。
- 三本国内新书结论与冲突观点：中国营养学会《中国宠物营养与喂养指南》2024、陈金发等《犬猫天性营养学》2025、丁丽敏《宠物营养与饲养学》2023 的蒸馏要点，以及"碳水/天性饮食立场""无谷升糖声称""生骨肉"等观点的出处标注（§十二）。
- 常见营养健康议题的精准营养干预与剂量：体重管理（减重能量 80% DER、安全速率）、皮肤被毛（ω-3/锌/生物素剂量）、胃肠（纤维/益生菌）、泌尿（结石分型干预）、口腔（刷牙金标准/VOHC）、关节（葡萄糖胺/软骨素/ω-3 剂量）、血糖（一致性/低 GI/低碳水）、肝脏（限蛋白仅限 HE、MCT、SAMe/水飞蓟素）、**心脏（ACVIM 分期限钠区间、牛磺酸/肉碱、恶病质）**、**肾脏（IRIS 分期限磷：2 期 0.9–1.45 mmol/L、3 期 <1.6、4 期 <1.9；猫 3 期前蛋白不低于 30% DM）**、**食物过敏/CIE（水解或新型蛋白排除试验 6–8 周胃肠道 / 8–12 周皮肤，零零食）**、**胰腺炎（犬脂肪 ≤10% DM、不推荐长期禁食、猫不主张严格低脂）**，另含**诊断视角鉴别表 + 营养处方四步法**（§12.6）。
- 找开源工具/数据库：宠物营养计算、配方软件、原料成分表（GitHub 检索）。
- 用户显式要求「联网补充」「查最新研究」「完善知识体系」。

## 核心能力（Core Capabilities）

### 1. 本地知识库查表
读取 `references/nutrition_needs.md` 获取已蒸馏的**综合知识库**（13 章：基准统一 / 能量 / 蛋白·必需氨基酸 / 脂肪·必需脂肪酸 / 碳水化合物·纤维 / 矿物质 / 维生素 / 水 / 生命阶段 / 标准监管 / 功能性争议 / 配方应用 / 宠物食品 + **§十二 本土指南与中文专著（2023–2025）** + **§12.6 健康议题精准营养干预剂量（12 议题 + 诊断视角）** + **§十三 宠物食品（原料组成/分类/加工工艺/处方粮对照）** + **§9.5 法规变更追踪 2024–2026** + **§2.1.1/§5.6 来源形态与生物利用率对照**），覆盖维持·生长·妊娠·泌乳·老年各阶段与犬猫分列，并含书籍级原理、跨标准对照、三本国内新书蒸馏、冲突观点标注（§12.5）及 12 大健康议题干预剂量与营养处方四步法。

### 2. 基准换算与 MER 估算
调用 `scripts/nutrient_calc.py`（确定性、无依赖）：
- `dm2kcal` / `kcal2dm`：DM(假定 4000 kcal/kg) ↔ 每 1000 kcal ME 互转。
- `metabw --dog/--cat`：代谢体重（犬 BW^0.75；猫 BW^0.67，BCS>5 用 0.4）。
- `mer --dog/--cat`：维持能量需要量（犬 132×BW^0.75，按 active/pet/senior 修正；猫按 250kcal@4kg 锚点）。
- `me`：犬粮 ME 预测（GE=5.7P+9.4F+4.1(NFE+纤)；消化率=91.2−1.43×粗纤维%；ME=DE−1.04P）。

### 3. 联网完善知识体系
按 `references/web_enrichment_guide.md` 协议执行：
- 触发：缺口补全、法规/研究更新、开源工具检索、用户显式要求。
- 源分层：L1 权威标准（NRC/AAFCO/FEDIAF）→ L2 学术（PubMed/NCBI/知网）→ L3 开源（GitHub/HF）→ L4 专业社群。
- 国内检索必调 `multi-search-engine`（中文 7 引擎 + 国际 9 引擎，跨 ≥2 引擎交叉）；GitHub 用 `github` skill 或 WebSearch。
- **纪律**：引用用「文献/来源名称」而非文件名；每条带来源+检索日期+可信度层级；不覆盖只追加；回填 `references/enrichment_log.md` 与对应模块。

## 推荐工作流（Workflow）

1. **识别需求**：判断是「查表核算」还是「需要联网完善」。
2. **先查本地库**：读 `references/nutrition_needs.md` 给出核心数值；用 `nutrient_calc.py` 做基准换算/MER。
3. **判定缺口**：若问题落在「待联网完善项」或涉及最新研究/法规/开源工具，进入第 4 步；否则输出。
4. **联网检索与验证**：依 `web_enrichment_guide.md` 分层检索、跨源交叉、证伪后采纳。
5. **结构化输出**：表格呈现（含基准列、来源列、可信度列），标注 high/medium/low 与「原书缺口/新补/交叉验证」类别；不确定项打标回退人工。
6. **回填**：新结论追加至 `enrichment_log.md`，稳定结论同步更新 `nutrition_needs.md` 与勾选待办。

## 输出规范（Output Conventions）

- **基准统一**：跨标准比较一律先换算到「每 1000 kcal ME」再比。
- **安全系数**：原书 MR 为「最低」，商品粮用 RA/AI（通常 1.5~2×）；繁殖/泌乳高峰最高。
- **红线提示**：猫粮必加牛磺酸；大型幼犬钙 ≤4.5 g/1000kcal 且禁额外补钙；猫磷 <1.5 g/1000kcal ME（FEDIAF 2024）；高 PUFA 猫粮维生素 E ≥120 mg/kg 且 α-生育酚:PUFA ≥0.6；**维生素 D₃ 上限极窄——犬 ≤3000 IU/kg DM（AAFCO）/猫 NRC SUL 30000 但法定上限 AAFCO 30080、FEDIAF 2270 IU/kg DM，禁叠加鱼肝油/多脂海鱼/肝**（§6.3）；老年/肾病**勿盲目限蛋白**。
- **引用可追溯**：以文献名称标注（如「FEDIAF 2024 营养指南」「AAFCO 2023 官方公报」），不写裸文件名。
