# Word / DOCX 文档专家

把 Word 和 `.docx` 当 **OOXML 结构**来安全地读、改、造——修订、批注、编号、表格、页眉页脚、域，都能稳稳处理，换到 Google Docs / LibreOffice 也不跑版。

> 别再"删几个字能打开就行"地对付 Word 文档。能改、能来回存、不错版，才是文件是活的。

## 这个技能解决什么

| 场景 | 你能得到 |
|---|---|
| 改一个带修订/批注的审阅稿 | 最小改动保住讲稿结构，不整段重写毁掉留痕 |
| 给复杂文档调表格/页眉/编号 | 同时过 Word↔LibreOffice↔Google Docs 不碎版 |
| 目录/页码/交叉引用一显示就变 | 知道是"域"在作怪，改完刷新即稳 |
| 从别的文件复制内容进来 | 不静默带进一堆脏样式和编号定义 |
| 新建一份要长期编辑的文档 | 命名样式优先，之后都动得动、排得动 |

## 核心主张

- `.docx` 是 **ZIP 里的 XML**，不是纯文本；结构比"看得见的文字"重要。
- 读、造、改旧稿是**三件不同的事**，三条路分开走，别一把梭。
- 列表编号活在 `numbering.xml`，页面版式活在分节里，修订/批注/域各有独立结构——**都要当系统，不是当汉字**。
- 交付前在至少第二个编辑器心里过一遍往返兼容。

## 使用方法

直接说需求即可，本技能自带 AI 推理、零脚本：

- "帮我把这个 docx 的表格列宽统一成固定值，换到 Google Docs 别碎"
- "这篇是修订过的，帮我只把第三段改成新表述，别的留痕都别动"
- "新建一份带目录和页眉页脚的报告，A4"
- "这段是从别人文档粘进来的，帮我清掉脏样式"

详细实操（怎么拆包、怎么改 xml、保存前查什么）见 [`references/ooxml-workflow.md`](references/ooxml-workflow.md)。
