# 内容规则与质量规范

供 `帮我生成脑图` 技能在提取与大纲整理阶段查阅。

## 一、剔除规则（extract_content.py 内置）

行级正则词表（命中即丢弃该行）：

| 类别 | 示例 |
| --- | --- |
| 关注引导 | 点击上方蓝字、长按识别二维码、关注我们、订阅本号 |
| 互动引导 | 点赞、在看、分享、转发、收藏、留言、评论区、一键三连、星标、置顶 |
| 跳转引导 | 阅读原文、原文链接、往期回顾、推荐阅读、猜你喜欢、上一篇/下一篇 |
| 平台水印 | 预览时标签不可点、使用小程序、微信扫一扫 |
| 署名信息 | 编辑/排版/校对/审核/责编/来源/原标题/作者：xxx、投稿邮箱、商务合作 |
| 版权声明 | 免责声明、版权声明、内容仅代表、如有侵权 |
| 图注 | （图：xxx）、（图片来源：xxx）、配图、资料图、海报、截图 |
| 广告位 | class/id 含 ad、banner、promo、sponsor、recommend、related 等 |
| 结构噪音 | nav/header/footer/aside/figure/svg/iframe/script/style |
| 隐藏元素 | display:none、visibility:hidden、aria-hidden |

追加规则：核心字符 ≤ 2 的行、纯数字/日期行、装饰符号行（`———`、`•••`）均丢弃。

**扩展方式**：向 `scripts/extract_content.py` 的 `BOILERPLATE_PATTERNS` 列表追加正则即可；
`DROP_HINT` 负责按 class/id 丢弃整块，`DROP_TAGS` 负责按标签丢弃整块。

## 二、来源适配

| 来源 | 处理方式 | 兜底 |
| --- | --- | --- |
| mp.weixin.qq.com | `js_content` 容器 + `var msg_title`，首行自动补 `# 标题` | 抓取失败 → browser 滚动截图 + OCR |
| 普通网页 | `<article>` → 语义化 class/id（content/article/main/post/entry）→ 文字量最大的块 | 同上 |
| .docx | 段落 + Heading 样式 → 标题层级；表格 → `\|` 分隔行 | `pip install python-docx` |
| .pdf | pypdf 逐页取文 + 硬折行合并启发式 | `pip install pypdf` |
| .pptx | 每页标题 + 文本框条目 | `pip install python-pptx` |
| .md / .txt | 原样保留（.md 直接作为中间稿） | — |
| .html 本地 | 同网页 | — |

- 编码：按 Content-Type / meta charset → utf-8 → gb18030 → big5 依次尝试。
- HTML 中超长"标题"（> 60 字）自动降级为正文段落，避免误建分支。

## 三、脑图结构规范

```markdown
# 根标题            ← 1 个，来自文章标题
## 摘要            ← 必需，200 字左右（140–300）
## 一级分支 × 3–7   ← 对应文章的章节/主题
- 叶子短语 × 3–8    ← ≤ 30 字，关键词化
  - 二级叶子        ← 最多到第 4 层
```

**提炼手法**：

1. 合并同类项：多个并列句子 → 一条短语 + 二级展开。
2. 保留数字与专名：如"28 个法则""淄博烧烤"这类记忆点不要抹掉。
3. 因果/递进关系用层级表达，而不是"然后""因此"这类连接词。
4. 摘要写"是什么—核心观点—结论/价值"三段式，不罗列细节。
5. 单节点文字过长会被自动换行，> 30 字时主动精简。

## 四、质量自检表（生成后逐项核对）

- [ ] 摘要存在且在 140–300 字之间
- [ ] 根节点为文章标题，一级分支 3–7 个
- [ ] 无图片、二维码、图注、"点赞在看"类残留
- [ ] 叶子为短语，无整段复制
- [ ] 总节点 20–60 个
- [ ] HTML 双击可离线打开，缩放/折叠/导出可用
- [ ] 已用 present_files 呈现最终 HTML
